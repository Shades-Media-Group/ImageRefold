## Platform

web

Two surfaces share the Shades design system:

- **Figma plugin window** in Figma desktop and Figma in the browser: a 400 × 640 px iframe, drawn with the same tokens and controls as PageRecast's plugin.
- **The website**, imagerefold.shades.md: a static site on a Cloudflare Worker, in the same eleven languages as every Shades site: English (at `/`), French, Romanian, Russian, Spanish, Italian, Turkish, Hindi, Japanese, Simplified and Traditional Chinese. The plugin itself is in English for now.

## Stack

TypeScript, Preact, Vite and Vitest in a Yarn 1 workspace, the same as PageRecast. Encoding uses jSquash's WebAssembly builds of libwebp, libavif, MozJPEG and OxiPNG, embedded in the plugin and run in a Web Worker. ZIPs are written with fflate.

## Users

- **Product and UI designers** handing images to developers or publishing them, who need the smallest file that still looks right.
- **Developers** taking assets out of a design file for a website or an app, often at several sizes.
- **Teams whose Figma files have grown heavy** with photos far larger than they are shown.

They work in Figma all day and expect its density and conventions. Many work for companies that approve plugins only when they upload nothing.

## Product Purpose

Export any layer as a small WebP, AVIF, JPG or PNG, see the size before saving, make the images already in a file lighter, and bring new images in already compressed. Success means a designer exports once, with no second trip through another tool, and the files are as small as they can be without a visible loss.

## Positioning

A free, open-source and fully local image tool for Figma:

- **No paywall:** unlimited exports, no account, no trial.
- **No server:** the manifest allows no network access, so it is safe for any company's files, and nothing can go down.
- **The same result everywhere:** dedicated encoders, not the browser's own, so the output is identical in Figma desktop and in every browser.
- **Export, optimise and import in one plugin.**

Made by Shades Media Group.

## Operating Context

1. The user selects layers and opens ImageRefold.
2. **Export:** they choose a format, quality and sizes, check each file's size and the result at 100%, then download the files or a ZIP.
3. **Optimise:** with layers selected, or nothing for the whole page, the plugin lists image fills larger than they are shown and swaps in lighter copies. One undo step.
4. **Import:** they drop or choose images; each is compressed and shrunk to Figma's 4096 px limit, then placed or used as the fill of the selected layers.

## Capabilities and Constraints

**Constraints**

- **Free forever:** no payments, tiers, limits, trials, upgrade prompts or watermarks.
- **Local only:** `networkAccess.allowedDomains: ["none"]`. No backend, no analytics.
- **Licence:** MIT © Shades Media Group. The name and logo are reserved (TRADEMARKS.md).
- **Version:** 0.1.0, in development. Not yet in the Figma Community.

**Platform limits**

- Figma exports only PNG, JPG, SVG and PDF, with no quality setting: the plugin exports lossless PNG and encodes it itself.
- `figma.createImage` takes PNG, JPG or GIF up to 4096 px a side: imports and optimised fills are JPG (opaque) or PNG (transparent).
- Settings are kept with `figma.clientStorage`, on the user's machine.

**Terminology**

- **export:** files written from layers.
- **optimise:** replacing image fills in the file with lighter copies.
- **import:** bringing image files into Figma.
- **size:** a scale (0.5×–4×) or an exact width.

## Product Principles

1. **Show the size before the save.** Every file's size and saving is visible before anything is written.
2. **Never make it worse.** A PNG is never larger than Figma's own; an optimised image is swapped only when it is smaller.
3. **Free means free.** No limits and no upsell surface.
4. **Local by design.** No request leaves the plugin.
5. **Figma-native density.** 32 px rows, hairlines, one red action per view.
