# Contributing to ImageRefold

Thanks for helping make ImageRefold better. Bug reports, images that export badly, ideas and pull requests are all welcome.

## Report a problem

- **An image came out wrong?** Open an [export report](https://github.com/Shades-Media-Group/ImageRefold/issues/new?template=export.yml) with the format, quality and size you used. Attaching the original and the result helps most.
- **Something broke?** Open a [bug report](https://github.com/Shades-Media-Group/ImageRefold/issues/new?template=bug.yml).
- **An idea?** Start a [discussion](https://github.com/Shades-Media-Group/ImageRefold/discussions) or open a [feature request](https://github.com/Shades-Media-Group/ImageRefold/issues/new?template=feature.yml).

Security issues go through [private reporting](SECURITY.md), never public issues.

## Set up

You need Node 22 (see `.nvmrc`) and Yarn 1.

```bash
git clone https://github.com/Shades-Media-Group/ImageRefold.git
cd ImageRefold
yarn install
yarn verify
```

## How the code is organised

| Path                           | What it does                                                                      |
| ------------------------------ | --------------------------------------------------------------------------------- |
| `apps/figma-plugin/src/main`   | The Figma side: selection, PNG export, image fills, placing imports               |
| `apps/figma-plugin/src/ui`     | The plugin window and the encoder worker (WebP, AVIF, MozJPEG, OxiPNG)            |
| `apps/figma-plugin/src/shared` | Messages between the two, and file naming                                         |
| `apps/site`                    | The website, imagerefold.shades.md, served by a Cloudflare Worker                 |
| `assets/brand`                 | Logo files and banners, generated by `scripts/brand.mjs` and `scripts/assets.mjs` |
| `scripts`                      | Brand, asset, SEO check and release scripts                                       |

To work on the plugin window without Figma, run `yarn dev:plugin` and `yarn dev:harness`, then open `http://localhost:4318/apps/figma-plugin/harness.html` (add `?theme=dark` for Figma's dark theme). To try it in Figma, import `apps/figma-plugin/manifest.json` under **Plugins → Development**.

## Before you open a pull request

```bash
yarn verify      # typecheck, lint, unit tests, plugin and website builds
```

- Keep each pull request to one change, and add a test when you change encoding or export behaviour.
- Use [Conventional Commits](https://www.conventionalcommits.org/): `feat(figma-plugin): …`, `fix(site): …`, `docs: …`. The changelog is generated from them.
- Interface changes follow the design rules in [CLAUDE.md](CLAUDE.md#design-rules). Include before and after screenshots in light and dark.
- Generated files (`assets/brand/**`, `apps/figma-plugin/src/ui/kit/brand.ts`) are never edited by hand: change the script and run it.

## Ground rules

- ImageRefold stays free, with no accounts, limits or paid tiers.
- Images never leave the user's computer. No analytics or remote logging, and no network access in the plugin.

By contributing you agree that your work is released under the [MIT License](LICENSE), and that you'll follow the [Code of Conduct](CODE_OF_CONDUCT.md).
